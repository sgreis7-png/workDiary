# יומן בטיחות — טופס הדרכה יומי (Toolbox Talk) — Design

**Date:** 2026-08-16
**Status:** Approved by user

## Purpose

מנהל עבודה מחתים את העובדים באתר על טופס הדרכת בטיחות יומי ("טופס הדרכה יומי / Tool box"),
המבוסס על הטופס הרשמי (דף החתמה בטיחות אתר בנייה). הטפסים נשמרים לפי פרויקט כמו רשומות
היומן, וניתנים לחיפוש לפי פרויקט, תאריכים ושמות עובדים.

## Decisions (from brainstorming)

- **מקור שמות עובדים:** הקלדה חופשית (שם + ת"ז) עם השלמה אוטומטית מעובדים שנרשמו
  בטפסים קודמים של אותו פרויקט. אין ניהול מאגר עובדים נפרד.
- **נושאי הדרכה:** 10 הנושאים מהטופס הרשמי כברירת מחדל. אדמין יכול לערוך את הרשימה.
  בכל טופס מנהל העבודה מסמן אילו נושאים הועברו (ברירת מחדל: כולם).
- **עריכה:** טופס שנשמר נשאר פתוח לעריכה (הוספת עובד שהגיע מאוחר וכו').
- **חתימה:** וקטורית — קווי החתימה נשמרים כנקודות (JSON), ~1–3KB לחתימה.
  אין תמונות, אין storage bucket. מרונדרת כ-SVG בתצוגה, בהדפסה וב-PDF.
- **ייצוא:** תצוגת הדפסה במבנה הטופס הרשמי + שליחה במייל דרך Outlook/Graph
  כמו דוחות היומן הקיימים.
- **לא במרכז הבקרה:** יומן הבטיחות לא מוצג ולא נספר במסך מרכז הבקרה.

## Data model

### Table `safety_forms` (new migration)

| column | type | notes |
|---|---|---|
| id | uuid PK | |
| project_id | uuid FK → projects | |
| training_date | date | ברירת מחדל היום |
| topics | jsonb | מערך מחרוזות — הנושאים שסומנו כהועברו |
| workers | jsonb | `[{ name, id_number, signature, signed_at }]` |
| instructor_name | text | ברירת מחדל: שם המשתמש המחובר |
| instructor_qualification | text | כשירות המדריך |
| instructor_signature | jsonb | אותו פורמט וקטורי |
| created_by | text (email) | |
| created_at / updated_at | timestamptz | |

`signature` format: מערך משיחות (strokes), כל משיחה מערך נקודות `[x,y]` מנורמלות
ל-viewBox קבוע, אחרי דילול (point simplification) לצמצום גודל.

### Table `safety_topics` (new migration)

רשימת נושאי ההדרכה, ניתנת לעריכה ע"י אדמין: `id, label, sort_order, active`.
Seed: 10 הנושאים מהטופס הרשמי.

### RLS

כמו שאר הטבלאות — `is_member()` לקריאה ולכתיבה; `safety_topics` כתיבה לאדמין בלבד.
לפי מודל האבטחה הקיים (migrations 0030–0039).

## Screens & routes

| route | screen | perm |
|---|---|---|
| `/safety` | רשימת טפסים: קיבוץ לפי פרויקט, סינון לפי פרויקט + טווח תאריכים + חיפוש שם עובד | `area="safety"` |
| `/safety/new` | טופס חדש | `area="safety"` edit |
| `/safety/:id` | תצוגת טופס במבנה הרשמי + הדפסה + שליחה במייל | `area="safety"` |
| `/safety/:id/edit` | עריכת טופס קיים | `area="safety"` edit |
| admin: ניהול נושאים | בתוך מסכי האדמין הקיימים | admin |

הרשאת `safety` מצטרפת למנגנון ההרשאות הקיים (`RequirePerm`) ולניהול המשתמשים.
ניווט: פריט חדש בתפריט (Shell) — לא במרכז הבקרה.

## Signature capture flow

1. בטופס, שורת עובד עם שם + ת"ז ותא "חתימה".
2. לחיצה על התא פותחת משטח חתימה במסך מלא (canvas, מותאם מובייל).
3. העובד חותם באצבע; כפתורי "נקה" ו"אשר".
4. באישור — הנקודות מדוללות, מנורמלות ונשמרות ברשומת העובד + חותמת זמן.
5. בתחתית הטופס: הצהרות (מהטופס הרשמי), שם המדריך, כשירות, וחתימת המדריך באותו מנגנון.
6. "שמור" — הטופס נשמר; נשאר פתוח לעריכה.

טיוטה מקומית (localStorage) בזמן מילוי — שלא יאבדו חתימות אם הדפדפן נסגר באמצע.

## Search

- סינון צד-לקוח/שרת לפי `project_id` + טווח `training_date`.
- חיפוש שם עובד: `workers @> ...` / טקסט על jsonb (אינדקס GIN אם צריך).

## Print & mail

- תצוגת `/safety/:id` בנויה במבנה הטופס הרשמי (כותרת, נושאים, טבלת עובדים עם
  חתימות SVG, הצהרות, מדריך) עם CSS להדפסה נקייה.
- שליחה במייל: אותו מסלול Graph/sendMail של דוחות היומן, עם גוף HTML של הטופס.

## Out of scope (YAGNI)

- חתימה מרחוק ממכשיר העובד.
- התראות/תזכורות בטיחות.
- הצגה או ספירה במרכז הבקרה.
- מאגר עובדים מנוהל.

## Testing

- Unit: דילול/נרמול חתימה (round-trip, גודל תקרה), פורמט workers jsonb.
- API: יצירה/עדכון/שליפה עם RLS.
- ידני במובייל: חתימה באצבע, סיבוב מסך, טיוטה מקומית.
